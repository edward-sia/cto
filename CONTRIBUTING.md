# Contributing

Thanks for considering a contribution to Cambrian Tree Orchestrator.

## Development

```bash
npm install
npm run typecheck
npm test
npm run lint
```

## Pull Requests

Please keep changes focused, include tests for behavior changes, and update the README or docs when CLI behavior changes.

## Local State

Do not commit `.env`, `.cambrian-tree/`, `node-*/`, generated run outputs, local worktree artifacts, or private planning notes.
